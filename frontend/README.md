# Frontend de Asistencia UTP

Interfaz React y TypeScript para alumnos, docentes y administradores.

Consulta el [README principal](../README.md) para instalar el proyecto, configurar la conexión con el backend y seguir el manual de usuario. La preparación de Render está en [docs/RENDER.md](../docs/RENDER.md).

Desde esta carpeta:

```sh
npm ci
npm run dev
```

Comprobaciones: `npm run build` y `npm run lint`.
